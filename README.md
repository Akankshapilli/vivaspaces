## Overview

**Viva Spaces** is a property-tech platform focused on digital real estate and accommodation booking experiences. The project combines modern UI design with scalable frontend architecture — built to handle property discovery, listing views, and booking workflows with a clean, conversion-focused interface.

Contributed as **Frontend Developer & Product Designer** — responsible for UI design, responsive implementation, user flow optimisation, and design-to-development handoff.

## Features

- 🏠 **Property Discovery** — Intuitive browsing and search experience for listings

## Getting Started

```bash
git clone https://github.com/Akankshapilli/viva-spaces.git
cd viva-spaces
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
